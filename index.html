    How it works

    Click a node to make it a target. The cheapest tree that reaches every target is rebuilt each time. When two routes cost the same, it takes the one with more of your preferred small passives (⋯ → Path preferences).

    Click a target to drop it. Click a node on the path to pin it. Right-click (or Block mode) blocks a node so paths avoid it.

    Prefer the in-game feel? Turn off Smart path for manual pathing: each click takes the shortest path from what you have, and clicking an allocated node refunds it and anything cut off.

    Focus dims the map except the mechanics you pick, from a Generic list and a League mechanics list. Type to search them by name or by node text; Enter toggles the first match.

    Notables with a choice of effects open a picker when you click them; the summary shows only the effect you chose. Click the notable again to change it.

    Use ‹ › next to the slider (or the arrow keys) to step through your targets in the order you added them, with the points each one costs. Drag the slider to see the tree at any point count.

    The tree name at the top lists your saved trees: open, rename, share, compare or delete them, or open a link someone sent you. Save (Ctrl+S) keeps the tree in this browser; Share copies a link anyone can open.
