How it works

Click a node to make it a target. The cheapest tree that reaches every target is rebuilt each time. When two routes cost the same, it takes the one with more of your preferred small passives (Plan tab → Path preferences).

Click a target to drop it. Click a node on the path to pin it. Right-click (or Block mode) blocks a node so paths avoid it.

Prefer the in-game feel? Switch Pathing to Manual: each click takes the shortest path from what you have, and clicking an allocated node refunds it and anything cut off.

Notables with a choice of effects open a picker when you click them; the summary shows only the effect you chose. Click the notable again to change it.

The Plan tab lists targets in the order you will level them. Drag or use the arrows to reorder; point numbers update. Use ‹ › next to View at point (or the arrow keys) to step through the tree one target at a time, or drag the slider to any point count.
